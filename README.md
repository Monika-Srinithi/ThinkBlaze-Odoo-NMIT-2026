# ThinkBlaze — Odoo × NMIT Bangalore Hackathon 2026

> **A modern, scalable and user-centric solution built for the Odoo × NMIT Bangalore Hackathon 2026.**

ThinkBlaze is a full-stack web application developed as part of the **Odoo × NMIT Bangalore Hackathon 2026**, designed to address the given problem statement through a practical, scalable and intuitive digital solution.

The platform combines a modern frontend with a structured backend to provide a seamless experience for users while keeping the system modular and extensible.

---

## 🚀 Features

* Modern and responsive user interface
* Clean dashboard-driven experience
* Modular frontend and backend architecture
* Real-time data interaction
* User-centric workflows
* Scalable application structure
* Responsive design for different screen sizes
* Interactive components and visual analytics
* REST API-based backend communication
* Production-ready frontend build

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Monika-Srinithi/ThinkBlaze-Odoo-NMIT-2026.git
```

### 2. Navigate to the project

```bash
cd ThinkBlaze-Odoo-NMIT-2026
```

---

## ▶️ Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

The development server will provide a local URL in the terminal.

---

## ▶️ Run the Backend

Navigate to the backend directory:

```bash
cd backend
```

Install the required dependencies according to the backend configuration and start the server.

## 🎯 Hackathon Objective

ThinkBlaze was developed with the following principles:

* **Practicality** — solving a real-world problem rather than building a purely conceptual prototype.
* **Scalability** — designing the application so that additional modules and users can be supported.
* **Usability** — providing an intuitive interface with minimal complexity.
* **Reliability** — maintaining a structured separation between frontend, backend and data layers.
* **Extensibility** — keeping the architecture modular for future improvements.
